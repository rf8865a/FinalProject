This is my final project. After spending last summer working at an estate planning firm part of my job was checking documents to ensure that names were spelled correctly and that the dates had been added correctly. There were more misspelled names than I thought there would be and "command f" was not helpful because misspelled names would not appear when searching with the correct spelling. This was mainly seen when there was more than one way to spell a name and with dates it would happen when signing meeting would get pushed back and dates would not be updated on the documents. That is why I decided to create a code/AI agent that would check the spelling and dates of all the names in a will or trust. This is useful because it allows the user to see where the names are misspelled and how they were misspelled and then create a new document with the corrected spelling and dates where necessary. I created a master file (correctcontents.txt) with the correct spelling and dates for each fake will or trust I created. I created 6 fake wills and 4 fake trusts to ensure that the code did what it was supposed to. Some are simple and some are more complicated with more spelling errors and more text. 

How to use the code: The code only needs to be changed in two places on line 80. The code needs to know which document is being used in order to cross check and update the spelling and dates. This means that on line 80 the name of the original document needs to be given. For example, if I want to check the spelling and dates in will1.txt I need to ensure that that is what is written on line 80 or it will not work. There are two places on the line where this would appear. It is at the front and then near the end of that line of code. Once this is updated in both places on line 80, the code should (and did) reproduce a new document with a name that had not been used before with the now correct spelling and date based on the master file (correctcontents.txt) I created. You know the code worked when a new document is created with all of the original content with the incorrect spelling and dates replaced with the correct versions. 

After our last class I realized that my code was not sufficient and I was making too many changes to the actual code rather than just changing one or two things. I did not have a master file originally. Before, I needed to change my descriptions and content each time I wanted to run the code with a different document. Creating a master file made it much easier to plug in what I wanted to do because all I needed to edit in the actual code was which original document I wanted the AI to read and update, rather than telling the AI what to name the document and the name of the original document and the correct spelling and dates. It is now all in one file. I also originally had a separate check_spelling, fix_spelling, fix_date, check_date in my tool schemas and this was becoming more complicated and having the AI basically do everything twice. I realized that I could just combine the two and ask the AI to read both the spelling and the dates at the same time, so I edited my code to have only a check_content for reading the documents and fix_content for the rewriting of the document. I left the list schema as it was. 

An error I ran into once I updated the code was either that the AI was producing a document with only the corrected names and dates or was not actually replacing the incorrect names and dates and just creating a duplicate of the original document. I had to play around with the descriptions and the content sections. By adding "in one new file" seemed to solve the issue of getting three new documents rather than just one. I did not want to be too broad, which I was at first, and therefore not getting the exact result I wanted. Once I realized the more specific I got, the better the outcome was. I also added "do not shorten the original document" and that seemed to help with the issue of only getting the names back. I also added "entire original document" and that helped as well to make sure the code was reproducing the entire document not just the information that was wrong in a new document. Once I edited that the code worked as I wanted it to.
